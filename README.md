# Árvore Genealógica Interativa — Família Luna

Site estático criado a partir da postagem **“Árvore Genealógica da Família Luna”**, de Luiz Domingos de Luna.

## Recursos

- mapa genealógico navegável com zoom e pan;
- busca por pessoa;
- destaque de conexões imediatas;
- árvore detalhada expansível;
- índice alfabético;
- notas sobre homônimos e inconsistências da fonte;
- layout responsivo para celular e desktop.

## Publicação no GitHub Pages

Este projeto é 100% estático. Para publicar, basta usar `index.html` na raiz do repositório e habilitar o GitHub Pages para a branch principal.

## Fonte

http://livrodigitalartigosdeluizdomingos.blogspot.com/2014/01/arvore-genealogica-da-familia-luna.html

> A organização visual não constitui validação genealógica independente. Grafias, homônimos e ambiguidades foram preservados quando não havia evidência suficiente para corrigi-los.
